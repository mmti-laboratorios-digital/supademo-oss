## TL;DR (Executive Summary)

1. **Tier 1 USD players investiram pesado em AI agents + MCP servers em Q3-Q4 2026.** Supademo é o leader absoluto em AI surface (80+ MCP tools, AI Demo Agent, AI Command). Storylane segurou preço em Growth tier ($625 mensal) e rebaixou sandbox para Enterprise — sinal de inflexão. Navattic consolidou como produto de leadership B2B.
2. **Tier 2 BR players estão em fases diferentes de maturidade.** Getdemo é o "feature-richer BR" (Sage Story + AI agent + Tours), mas 100% sales-led. Fluidz é o "preço público honesto" (R$105/mês básico). GuiaFlow e Interdemo são early-stage.
3. **A Chrome Web Store é o canal PLG battleground em tier 1.** Supademo/Arcade/Storylane: 30k-50k+ installs cada. Em pt-BR, **GuiaFlow tem 36 installs e zero reviews — gap de mercado claro**.
4. **Infra-side, todos os Tier 1 estão estáveis (zero incidentes reportados em Q3-Q4).** Status page não é vetor de marketing.
5. **NPS/CSAT inferido, mas dados primários bloqueados:** Storylane 4.9/5 em Chrome Store; Supademo/Arcade 4.8; sem leitura direta de G2 NPS no escopo desta sessão.
6. **Paid ads: o setor gira em torno de "alternative" keywords** (Storylane alternative, Supademo alternative). PLG conversion benchmark não capturado.

## Mudanças macro detectadas em Q3-Q4 2026

### 1. **Storylane rebalanceou o preço — sinal de inflexão**

Storylane Growth era acessível em ~$500/mês; agora **$625/mês mensal ou $500 anual**. Sandbox desceu para Enterprise. **Implicação:** Storylane está forçando upsell em quem precisa de feature avancada, subsidia quem fica em screenshot mode. É um pivô de "valor em tier superior" para o Tier 1.

Para DemoBR: posicionamento de **preço público baixo + feature completa em tier acessível** ainda é o gap que Supademo Scale preenche. Storylane abriu o flanco.

### 2. **Supademo construiu uma vantagem de AI surface**

- 80+ MCP tools (vs Storylane 20+, Navattic similar, Arcade adjacente)
- AI Demo Agent em credit-based pricing
- AI Command in-product (bulk-edit workspace via linguagem natural)
- Voice cloning + Voiceover 2.0
- Sandboxes em $350/mo vs Enterprise-only da competição

**Para DemoBR:** é muito caro replicar. Sugere-se:
- **Foco em AI Agent conversacional em pt-BR** (gap claro).
- Não tentar replicar Supademo Scale — focar em **Tier 2 BR + LGPD + AI Agent pt-BR** como vantagem.

### 3. **MCP virou commodity de Tier 1**

Supademo, Storylane, Navattic, Arcade: todos têm MCP server. **Cada um com 20-80+ tools.** A escolha **não é se tem MCP**, mas **qual o scope dos tools**.

**Para DemoBR:** MCP é table-stakes. Sem MCP server, DemoBR não consegue competir em 2027. Planejar para release v1.0 do MCP é uma necessidade.

### 4. **AI agents estão virando produto, não feature**

Storylane **RepX** ($2k/mo, tráfego-metered). Supademo **AI Demo Agent** (credit, desde $99). Navattic **Agents** (conversations-based). Loom **Record for Agents** (flat fee).

**Para DemoBR:** o nicho "AI sales agent conversacional" ainda está aberto em pt-BR. Players globais não falam português decente — DemoBR pode ser o "AI agent for B2B Brazil".

### 5. **Sandbox + HTML demos viraram table-stakes em Tier 1**

Storylane: Enterprise only.
Navattic: Growth $50+ sales.
Supademo: $350/mo público.
Arcade: Enterprise só com HTML capture.

**Para DemoBR:** sandbox/HTML demo é o "Tier 1 wedge". Sem isso, DemoBR é automaticamente Tier 2. **Vale considerar** mesmo que seja no plano Enterprise.

### 6. **Chrome Web Store ratings como proxy de CSAT/NPS**

**Para DemoBR:** extension rating é vetor rápido de credibilidade. Superação de 4.7+ é viável em 6 meses.

### 7. **Pricing público de Tier 2 BR é fragmentado**

| Player BR | Pricing transparency |
|---|---|
| Getdemo | Sales-only (todos os tiers são Fale Conosco) |
| Fluidz | **Public R$105-329** (R$1330/ano Profissional) |
| GuiaFlow | Não publicado |
| Interdemo | Não publicado |

Fluidz é o único com pricing honesto e publicado em BRL — **forte sinal de transparência** comparativa.

## Tese DemoBR — derivada dos movimentos Q3-Q4 2026

### Curto prazo (Q1 2027): **MCP + Free tier + AI Agent em pt-BR**

1. **Adotar Stripe-like "freemium agressivo"** — 5+ demos no Free, unlimited views (igual Supademo) ou 20 demos no Essencial (R$105 equivalente Fluidz).
2. **MCP server com 20-30 tools no Free/Basic/Standard.** Tornar MCP defensivo.
3. **AI Agent conversacional em pt-BR** — usar OpenAI/Anthropic via Azure Brazil ou serviço local, com:
   - Voice em pt-BR (ElevenLabs suporta — voz "Aria" / "River" etc.).
   - Persona treinada em casos de uso SaaS B2B Brasil.
   - First-class: WhatsApp integration (ClienteInterativo + WhatsApp Business API).
4. **LGPD-compliant** (LGPD-aware data retention UI + auditoria).

### Médio prazo (Q2-Q3 2027): **Vertical wedge + sandbox + integrations CRMs BR**

1. **Sandbox demos** como feature diferenciada para tier Professional (não Enterprise-only).
2. **Integração nativa** com WhatsApp Business, RD Station, HubSpot BR, Salesforce BR.
3. **Templates verticais** (fintech, edtech, healthtech, retailtech) — curva de atalho para o usuário.
4. **Localização** não só pt-BR mas pt-AO, pt-MZ (expandir LatAm).

### Longo prazo (Q4 2027+): **AI-native + ecosystem**

1. **AI Demo Agent conversacional** em pt-BR que fala com clientes via WhatsApp.
2. **MCP server** com tools que vão além de demos — connecting to CRM, calendar, billing.
3. **DemoBR Marketplace** — templates de demos por vertical, comunidade de contributors.

## O que NÃO fazer (lições dos competidores)

1. **Não tentar ser Supademo em Scale tier.** Storylane tentou, está sentindo churn. Diferenciar.
2. **Não bloquear features em Enterprise-only** arbitrariamente. É o que Storylane está fazendo, e está gerando exit-customer quotes.
3. **Não ter apenas um canal paid ads** — deficiência vista nos BR players. Getdemo e Fluidz não têm investido em marketing visível.
4. **Não negligenciar Chrome Web Store como canal PLG** — é o primeiro stop na jornada de descoberta. GuiaFlow é exemplo de como *NÃO* fazer (extension sem ratings, dev URL fraca).
