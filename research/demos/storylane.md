## Modelo de negócio
SaaS B2B com **Demo Suite** (interactive demos + sandboxes + hubs) e **RepX** (AI website agent). Planos (fonte third-party levelupdemo.com, 2026): Free → Starter ~$50/mo → Growth ~$625/mo → Premium ~$1.500/mo → Enterprise (custom). RepX é usage-based conversacional.

## Identidade visual (IDE)
- Logo gradient roxo-rosa muito característico + wordmark preta.
- Site dark/light com animações Lottie (3D-feeling).
- Posicionamento explícito: "Buyer enablement", "Finer Demos Club" (comunidade).

## Funcionalidades

### 1. Captura
- Chrome Extension, Desktop app (Mac).
- HTML capture (clone de front-end).
- AI-assisted generation: **"Don't just build demos, prompt them"** (Storylane MCP).

### 2. Editor
- Hotspots e tooltips.
- Personalization (variables, branching).
- Custom themes.
- AI voiceover / avatar.
- Chapters, branching logic.

### 3. Player / Sharing
- Embed (iframe).
- Share por link.
- Hub digital sales room (Hubs) — mistura demo + vídeo + docs + pricing + security.
- Publicação de Variant por persona.

### 4. **RepX** (diferencial único entre top 3)
- Website agent conversacional que **runs demos e responde perguntas** 24/7, qualifica ICP, marca reuniões.
- Praticamente um chatbot LLMs com acesso a biblioteca de demos + vídeos.

### 5. Analytics
- Demo Signals: o visitante chegou até que step, em qual demo converteu, por canal.
- Deal Intelligence.
- Pipeline impact.
- A/B testing nativo entre demos.
- Buyer Circle Discovery.

### 6. Integrações
Salesforce, HubSpot, Slack, Marketo, Outreach, Salesloft, Gong, Highspot, Seismic, Google Analytics, Zapier, etc.

## Diferenciais vs Supademo
- **RepX como produto separado** — primeira "AI Demo Agent" empacotada como produto autônomo, antes de Supademo. Capacita também webchat.
- **Hubs (Digital Sales Room)** robustos — uma URL contém demos + docs + vídeos + calendário.
- **Storylane MCP server** próprio.
- UX polida — citou G2 "UX is fantastic ... innovation".
- AI voice avatars + AI translations.

## Stack detectável
- Site é Webflow (`cdn.prod.website-files.com/60aacdcdcc32cf61b05512fb`).
- App é plataforma proprietária; autocomplete e auto-save client-side com WebSockets.
- 4.7/5 rating consistente em G2/Capterra.

## Pontos fracos / reclamações
- Planos Starter ~$50/mo e Premium ~$1.500/mo — forte jump para times pequenos.
- Storage de demos em HTML clone pode quebrar se o produto atualizar (mesmo problema do Supademo).
- Limite no número de visualizadores nas primeiras tiers (pay extra).
- Sem plano brasileiro dedicado (Pix / NF-e / suporte em PT-BR).
